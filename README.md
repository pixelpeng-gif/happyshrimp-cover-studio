# HappyShrimp Cover Studio（虾米社媒封面编辑器）

- [通过 GitHub Pages 在线使用](https://pixelpeng-gif.github.io/happyshrimp-cover-studio/)
- [备用网页链接](https://xiami-cover-studio-2026.pixel9684.chatgpt.site)
- [下载确认版 ZIP 代码包](./虾米社媒模版-Web代码包-确认版.zip)

确认版代码包包含 `index.html`、`assets/` 和 `tools/`，共 114 个文件。仓库通过 [GitHub Actions](./.github/workflows/deploy-pages.yml) 解压该代码包并发布到 GitHub Pages。

本地使用：解压后在包含 `index.html` 的目录启动静态网页服务器，例如运行 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。
